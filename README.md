## ⚡ Getting Started & Local Development

### Prerequisites
- Node.js `v20.x` or higher
- npm `v10.x` or higher

### Installation & Run

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Al3xxDev/Portfolio.git
   cd Portfolio
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build Production Bundle**:
   ```bash
   npm run build
   ```
   Outputs the compiled production bundle into the `dist/` directory.

5. **Serve Production Build Locally**:
   ```bash
   npm run preview
   ```
